STUDIO BEAUTY - V7 ICONO DE APP CORREGIDO

Esta versión corrige el icono de la app instalada:
- El logo de Studio Beauty ahora ocupa mucho más espacio dentro del icono.
- Se añadió icono específico para iPhone/iPad.
- Se añadió favicon para el navegador.
- Se forzó una versión nueva para evitar que el celular siga usando el icono anterior.

IMPORTANTE:
Después de subir esta versión:
1. Espera 1-2 minutos.
2. Elimina de la pantalla de inicio la app/atajo anterior.
3. Abre de nuevo la agenda en Chrome o Safari.
4. Vuelve a instalar/agregar a pantalla de inicio.

Si no eliminas el acceso anterior, el celular puede conservar el icono viejo.
